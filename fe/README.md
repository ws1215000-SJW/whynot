# Battery Warning — Frontend

React + TypeScript + Vite 프론트엔드 프로젝트입니다.

## 실행

```bash
pnpm install
pnpm dev
```

## 검사 및 빌드

```bash
pnpm exec tsc --noEmit
pnpm build
```

## 폴더

- `src/App.tsx`: 배터리 화면, 게이지 및 공유 기능
- `src/index.css`: 전체 스타일
- `src/main.tsx`: React 진입점
- `public/`: 정적 자산

URL의 `charge` 쿼리 파라미터로 배터리 잔량을 공유할 수 있습니다.
